# Site content

These files are the single source for the site's text. Edit them here.

- `elements.json`: one entry per element: display name, benchmark, setting and module, summary,
  the "About the questions" description, grading, an example, release status and the reason an
  element is held. `grading_note`, `confidence`, `open_questions` and `sources` are working notes
  carried over from the drafts; the site does not show them.
- `steer_taxonomy.json`, `steer_me_taxonomy.json`: settings, modules and (for STEER) elements in
  paper order. `description` holds the papers' own paragraphs (typos fixed); `summary` is the short
  text on the benchmark pages. Module text marked `written_for_site` is not from a paper.

They replace the earlier element_descriptions.yaml and steer_taxonomy.yaml (October 2026),
which are no longer updated.
