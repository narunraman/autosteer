STEER-ME

Non-strategic microeconomics

STEER-ME covers the microeconomics of settings where nobody acts strategically: each agent takes prices as given and chooses what is best for it. The questions have numerical answers that are worked out from the economics. It is described in the STEER-ME paper (NeurIPS 2025), and a fixed sample of its questions is published as a dataset.

High-level findings

  • The stronger the model, the more systematic and diagnosable the errors. While many easy elements were solved correctly, on harder elements, strong models often made systematic errors. These were usually near misses that a non-expert would find hard to tell apart from the correct solution. Examples include deriving the Marshallian demand function when the Hicksian was asked for, collapsing several time periods into one, and using the wrong formula for the deadweight loss triangle. Because these mistakes are systematic, we could write the common wrong calculations as solvers, compute the answer each produces, and match model answers against them. This showed which mistake a model made and how often; some models used one particular wrong formula in nearly half their answers.
  • Models reasoned over the option set. Many of the hardest elements, models could not consistently solve in free text. In multiple choice, however, we observed models plugging each option into the problem to identify the correct answer, or using the options as hints about what the answer should look like. Scores fell when the options were hidden and fell again when no options were given at all.
