Generate questions and write new elements, on your own machine

autoSTEER is the application behind STEER and STEER-ME, and this site is autoSTEER running in its read-only public mode. Run it on your own machine to generate fresh questions for any element, or to write new elements for either benchmark.

{% if not public_mode() %}

You are running it now. Open developer mode.

{% endif %}

Run it

autoSTEER runs from a clone of its repository, which includes the template data. You need uv.

git clone https://github.com/narunraman/autosteer.git
cd autosteer

Generate questions

from autosteer.sampler.generator import ElementSampler

sampler = ElementSampler()
question = sampler.sample_question("consumer_surplus", seed=1)

Run it with uv run python inside the clone. The same seed always gives the same question, and the API serves the same questions over HTTP.

Develop new elements

uv run autosteer dev

This opens the site on your machine with developer mode, which walks you through writing an element, from example seeds to reviewed templates, and how to submit it.
