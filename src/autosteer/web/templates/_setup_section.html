Running a model on your own machine

Start a server that speaks the OpenAI chat API, then set OPENAI_COMPATIBLE_BASE_URL to its address, before starting autoSTEER or below for this session. On a Mac, with MLX:

uvx --from mlx-lm mlx_lm.server --model mlx-community/Qwen3-8B-4bit
export OPENAI_COMPATIBLE_BASE_URL=http://127.0.0.1:8080/v1

On a machine with an NVIDIA GPU, with vLLM:

uvx vllm serve Qwen/Qwen3-8B
export OPENAI_COMPATIBLE_BASE_URL=http://127.0.0.1:8000/v1
